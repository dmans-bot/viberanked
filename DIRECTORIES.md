## Dropped
- There's An AI For That (/submit): paid-only listing (historically ~$347+). It also blocks bots.
- Futurepedia: /submit-tool returns 404, and listing has been paid-only (~$247+).
- Toolify (/submit): free listing is not dependable. The paid option is the realistic path.
- AI Tool Hunt (aitoolhunt.com): the domain now serves unrelated APK spam, and /submit returns 404. Treat it as dead.
- Microlaunch: returned Cloudflare 526 (SSL error), so it is down right now.
- Note: Vibe Ranked is a directory/ranking site rather than an AI tool itself. Some AI-tool directories reject "directories of tools", so SaaSHub, AlternativeTo, PH, Peerlist, Uneed, Fazier and DevHunt are the safest bets.
